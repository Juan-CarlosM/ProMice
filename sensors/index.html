    Sensor simulations

    Texas instruments has the TI Magnetic Sense Simulator, a useful tool to simulate different magnet movemenst with respect to the sensor. You can set the geometry of your magnet, the kind of movement (joystick in this case), the sensor you're using and some other functionalities.

    The simulator uses Magpylib package to compute magnetic fields. In section Ball joint design We used Magpylib to simulate the magnetic field of a magnet of our choice. You can do interpolations to simulate different magnet-sensor gaps too.
